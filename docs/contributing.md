# Contributing

Contribution guidelines live in [CONTRIBUTING.md](https://github.com/isaac-tes/arxiv_scraper_cli/blob/main/CONTRIBUTING.md) at the repo root.

In short:

- `uv sync --group dev` to set up.
- `uv run pytest -q` must stay green.
- `arxiv_digest.py` stays a single file (it's pasteable into ChatGPT — load-bearing property).
- Update `CHANGELOG.md` under `[Unreleased]` for any user-visible change.
